Parsing Variable Values

For this section, I am retrieving and parsing metadata for the Public Use Microdata Sample (PUMS) Census API across four years: 2021, 2022, 2023, and 2024.

The variables we are interested in are AGEP, GASP, GRPIP, JWAP, JWDP, JWMNP, PWGTP, FER, HHL, SCH, SCHL, SEX, ST (for 2021, 2022)/STATE (for 2023, 2024), REGION, and DIVISION. The variables for each year will be stored in a list that will then be saved in a .rds file under the docs folder.

#Creating function to fetch and parse JSON variables for a single year
parse_year_metadata <- function(year){
  #Saves the url for whatever year the user is interested in
  url <- paste0("api.census.gov/data/", year, 
                "/acs/acs1/pums/variables.json")
  
  #Using GET() to contact the website and retrieve variable specifications
  response <- GET(url)
  
  #Parsing the JSON using fromJSON(rawToChar(...), simplifyVector = F). We use simplifyVector = F to ensure we return a list 
  parsed <- fromJSON(rawToChar(response$content), simplifyVector = F)
  
  #Extracting the `variables` element from the parsed data
  vars_list <- parsed$variables
  
  #Creating a vector of the variables we are interested in
  vars_needed <- c("AGEP", "GASP", "GRPIP", "JWAP", "JWDP", "JWMNP", "PWGTP",
                   "FER", "SCH", "SCHL", "SEX", "ST", "STATE", "REGION", 
                   "Division")
  
  #Subsetting vars_list to get only the variables we are interested in from vars_needed
  vars_selected <- vars_list[names(vars_list) %in% vars_needed]
  
  #Returning the list of the variables with their values
  return(vars_selected)
}

Parsing API Data

This function focuses on querying the PUMS API and returning a formatted tibble. I will first write a helper function to take what is returned by GET() and turn it into a formatted tibble.

The helper function will be wrapped into a function that will query the API. The function will have the following default values: survey year 2024, the numerical variables AGEP and PWGTP, the categorical variable SEX, and geography level State.

The valid values for year are: 2021, 2022, 2023, and 2024

For the numerical variables, PWGTP is always returned along with at least one other numerical variable: AGEP, GASP, GRPIP, JWAP (time), JWDP (time), and JWMNP. The function will turn variables into numeric values or time values when it is appropriate. For time values (i.e., JWAP and JWDP), a helper function is written to parse the time strings and return the midpoint as a time value and NA for missing time values

For the categorical variables, the options for the user are: FER, HHL, SCH, SCHL, and SEX where SEX is the default as mentioned above. The function will turn variables into factors using the appropriate year’s variable levels from my .rds file

For the geography level, the options for the user are: Region, Division, or State with State being the default as mentioned above. The “All” geography level is not included as the data being returned is too large. Furthermore, the user is only able to choose one of these geography levels to subset on for a given API call. If the user specifies multiple geography levels, specifies “All”, or provides a value that is not Region, Division, or State, the function will return an error.

A default value for the State, Region, or Division being subset on is specified if the user does not specify one themselves. The allowable values for the geographies are in the .rds file that I created earlier, or the user can input an “all” option that would return all values of either the State, Region, or Division.

Finally, a formatted tibble will be returned

Seeing as I know I’ll need to create two helper functions, one to take what is returned by GET() and converting it into a formatted tibble, and one to parse time strings and return the midpoint as a time value, I will start by creating these helper functions.

First I will create the first helper function that converts the GET() response object into a tibble

#Creating function
parse_api_response <- function(response){
  #Parsing the JSON content from the API response object
  raw <- fromJSON(rawToChar(response$content))
  
  #Converting data rows into a tibble, dropping the first row as those are the variable names, and using .name_repair = "minimal" to make sure the tibble doesn't create it's own column names
  df <- as_tibble(raw[-1, , drop = F], .name_repair = "minimal")
  
  #Setting the column names to row 1
  colnames(df) <- raw[1, ]
  
  #Returning the tibble
  return(df)
}

Now I am creating the second helper function with the help of a LLM that will parse time strings if the user inputs either JWAP or JWDP into midpoints in minutes

parse_time_string <- function(x) {
  #Check for NA, NULL, or non-workers
  if (is.null(x) || is.na(x) || grepl("^N/A", x, ignore.case = TRUE)) {
    return(NA_real_)
  }
  
  #Extract hours, minutes, and am/pm markers
  pattern <- "(\\d{1,2}):(\\d{2})\\s*([ap]\\.?m\\.?)"
  matches <- stringr::str_match_all(tolower(x), pattern)[[1]]
  
  if (nrow(matches) == 0) {
    return(NA_real_)
  }
  
  #Helper to convert extracted match row into minutes from midnight
  time_to_minutes <- function(match_row) {
    hr <- as.numeric(match_row[2])
    mn <- as.numeric(match_row[3])
    is_pm <- grepl("^p", match_row[4])
    
    if (hr == 12) {
      hr <- if (is_pm) 12 else 0
    } else if (is_pm) {
      hr <- hr + 12
    }
    
    return(hr * 60 + mn)
  }
  
  #Calculate minutes from midnight for all times in the range
  mins <- apply(matches, 1, time_to_minutes)
  
  #Compute range midpoint
  if (length(mins) >= 2) {
    start_min <- mins[1]
    end_min <- mins[2]
    
    midpoint <- (start_min + end_min) / 2
    return(midpoint %% (24 * 60))
  } else {
    return(mins[1])
  }
}

Now that my two helper functions I will need have been created, I can write the function that will query the PUMS API and return a nicely formatted tibble. The default values I will use are mentioned above in the beginning of this section.

get_census_tibble <- function(year = 2024,
                              numeric_vars = c("AGEP", "PWGTP"),
                              cat_vars = "SEX",
                              geo_level = "STATE",
                              geo_subset = NULL,
                              key = "9a9b66cf9a9433d327bf8c614f78a681d8df91b2"){
  
  #Checking to make sure the value specified for `year` is valid
  #Making sure the user only inputted one year
  if(length(year) != 1){
    #Produces error if more than one year is specified
    stop("Error: You may only use one value for 'year'")
  }
  
  #Making sure the user used a valid year i.e., 2021, 2022, 2023, 2024
  if(!year %in% c(2021, 2022, 2023, 2024)){
    #Produces error if invalid year is specified
    stop("Error: `year` is not valid. It must be 2021, 2022, 2023, or 2024")
  }
  
  #Checking to make sure the values specified for `numeric_vars` are valid
  #Defining the acceptable numeric variables
  accepted_numeric <- c("AGEP", "GASP", "GRPIP", "JWAP", "JWDP", "JWMNP",
                        "PWGTP")
  
  #Making sure that the numeric values inputted by user are valid
  if(!all(numeric_vars %in% accepted_numeric)){
    #Produces error if invalid numeric value is specified
    stop("Error: Invalid numeric variable specified")
  }
  
  #Making sure the PWGTP variable is included
  if(!"PWGTP" %in% numeric_vars){
    #Produces error if PWGTP variable is not included
    stop("Error: Variable 'PWGTP' must be included in `numeric_vars`")
  }
  
  # Making sure at least one other numeric variable along with PWGTP is 
  # specified. setdiff(numeric_vars, "PWGTP") returns all elements in 
  # numeric_vars that are not "PWGTP". Therefore if 
  # length(setdiff(numeric_vars,"PWGTP")) is less than 1, that means that the
  # only variable used was PWGTP
  if(length(setdiff(numeric_vars, "PWGTP")) < 1){
    #Produces error if only "PWGTP" is specified for numeric_vars
    stop("Error: At least one other numeric variable other than 'PWGTP' must 
    be specified")
  }
  
  #Checking to make sure the values specified for `cat_vars` are valid
  #Defining accepted categorical variables
  accepted_cat <- c("FER", "HHL", "SCH", "SCHL", "SEX")
  
  #Making sure the specified categorical variable is accepted
  if(!all(cat_vars %in% accepted_cat)){
    #Produces error if invalid categorical variable is specified
    stop("Error: `cats_var` must be one of `FER`, `HHL`, `SCH`, `SCHL`, or
         `SEX`")
  }
  
  #Making sure at least one value is specified for `cat_vars`
  if(length(cat_vars) < 1){
    #Produces error if no categorical variable is specified
    stop("Error: `cats_var` must be one of `FER`, `HHL`, `SCH`, `SCHL`, or 
    `SEX`")
  }
  
  #Checking to make sure the value specified for geo_level is valid. This 
  #checks to make sure only one geographical level is specified, the user did   #not specify "All", and the user specified one of "Region", "Division", or 
  #"State"
  if(length(geo_level) != 1 || geo_level == "All" || 
     !geo_level %in% c("Region", "Division", "State")){
    #Produces error if invalid geographical level is specified
    stop("Error: `geo_level` must be one of `Region`, `Division`, or 
         `State`")
  }
  
  #Setting `geo_level` specification to the Census API variable name 
  if(geo_level == "State"){
    geo_param <- "STATE"
  } else if(geo_level == "Region"){
    geo_param <- "REGION"
  } else if(geo_level == "Division"){
    geo_param <- "DIVISION"
  }
  
  #Specifying default values for the `geo_subset` variable if user provided 
  #NULL. For ease, the default subset for each geographic level will be 1
  if(is.null(geo_subset)){
    if(geo_level == "State"){
      #Using '01' as the Census State codes are two digits
      geo_subset <- "01"
    } else if(geo_level == "Region"){
      geo_subset <- "1"
    } else if(geo_level == "Division"){
      geo_subset <- "1"
    }
  }
  
  #Formatting the value specified for `geo_subset` to fit the format of the 
  #API URL. If user specified "All", it will return "*" as that is the symbol
  #that will return all states, regions, or divisions. If `geo_subset` has 1 
  #value it will return the value as a string and if it has multiple values,
  #it will return the value as a comma-separated string
  if(tolower(geo_subset[1]) == "all"){
    geo_sub_level <- "*"
  }else{
    geo_sub_level <- paste(geo_subset, collapse = ",")
  }
  
  #This part of the function will setup the url and the `GET` function.
  #The census API is 
  #https://api.census.gov/data/year/acs/acs1/pums?get=var_names&for=var
  #Therefore I need a way to automatically apply the variables for 
  #get= and for=
  #Saving url for the given year specified
  year_url <- paste0("https://api.census.gov/data/", year, "/acs/acs1/pums")
  
  #Combining numeric and categorical variables for get= part of url
  combined_vars <- unique(c(numeric_vars,cat_vars))
  
  #Joining variable names and separating them by commas for get= part of url
  get_param <- paste(combined_vars, collapse = ",")
  
  #Creating the for= part of url so we get for=geo_param:geo_sub_level,
  #making sure geo_param is lowercase to fit the url structure
  for_param <- paste0(tolower(geo_param), ":", geo_sub_level)
  
  #Calling `GET` function to retrieve API data
  response <- GET(year_url, query = list(get = get_param, 
                                         `for` = for_param, 
                                         key = key))
  
  #Saving response variable as a tibble
  census_tibble <- parse_api_response(response)
  
  #Reading in variable values from the `.rds` file I created earlier
  var_vals <- readRDS("data/pums_variables.rds")
  
  #Saving the variable values for the year specified
  year_vals <- var_vals[[as.character(year)]]
  
  #Now I can apply the necessary transformations for the numeric and 
  #categorical variables respectively. 
  #Starting with the numeric variables
  for (num_var in numeric_vars) {
  if (num_var %in% c("JWAP", "JWDP")) {
    
    #Safely retrieve the dictionary (checking $item and $values$item)
    var_meta <- year_vals[[num_var]]
    time_dict <- if (!is.null(var_meta$item)) var_meta$item else var_meta$values$item
    
    #Extract values and codes into a named mapping vector
    label_map <- unname(unlist(time_dict))
    names(label_map) <- as.character(names(time_dict))
    
    #Map raw API character codes directly ("0", "001", etc.)
    raw_codes <- sprintf("%03d", as.numeric(census_tibble[[num_var]]))
    time_strings <- label_map[raw_codes]
    
    numeric_results <- numeric(length(time_strings))
    
    for (i in seq_along(time_strings)){
      numeric_results[i] <- parse_time_string(time_strings[i])
    }
    
    census_tibble[[num_var]] <- numeric_results
    
  } else {
    census_tibble[[num_var]] <- as.numeric(census_tibble[[num_var]])
  }
}
  
  #Now for the categorical variables
  for(cat_var in cat_vars){
    #Saving the variable values from year_vals
    var_meta <- year_vals[[cat_var]]
    var_info <- if (!is.null(var_meta$item)) var_meta$item else 
      var_meta$values$item
    
    #Saving the levels from cat_vars using names() as the levels are the 
    #variable names
    levels_val <- as.character(names(var_info))
    
    #Saving the level labels from cat_vars using unlist() as the labels are 
    #stored in a list
    labels_val <- unname(unlist(var_info))
    
    #Converting variable to factor with appropriate levels and labels
    census_tibble[[cat_var]] <- factor(
      as.character(census_tibble[[cat_var]]), 
      levels = levels_val,
      labels = labels_val)
  }
  
  #Changes "ST" to "STATE" for 2021 and 2022
  if ("ST" %in% names(census_tibble)){
    census_tibble <- rename(census_tibble, STATE = ST)
  }
  
  class(census_tibble) <- c("census", class(census_tibble))
  
  #Returning the census tibble
  return(census_tibble)
}

Combining Years

Now that my function for creating a census tibble for a single year has been finished, I can now create the function that will let the user read in more than one year.

get_multi_year_census <- function(years, ...){
  
  #Iterates over each year user inputted
  list_of_tibbles <- lapply(years, function(y){
    
    #Creates a tibble for the year we selected and passes other
    #variables specified variables through
    df <- get_census_tibble(year = y, ...)
    
    #Removing the "census" class of the data frame because I was 
    #getting an error when I didn't remove it
    class(df) <- setdiff(class(df), "census")
    
    #Adding a variable indicating what year the data is from
    df <- mutate(df, year = y, .before = 1)
    
    return(df)
  })
  
  #Binding the rows of each tibble that was created
  combined_tibble <- bind_rows(list_of_tibbles)
  
  #Adding back the custom "census" class to the combined tibble
  class(combined_tibble) <- c("census", class(combined_tibble))
  
  return(combined_tibble)
}

Part 2: Writing a Generic Function for Summarizing

Now that we’re able to grab data from the PUMS API and save it in a tibble, we want to be able to summarize that data. This section of the project will do exactly that.

Numeric Summaries

This function will produce means for our numerical variables (ignoring the time variables) and counts for our categorical variables, treating years as categorical.

The function will take three arguments: the census tibble, the numeric variables to summarize, and the categorical variables to get counts for. By default it will summarize all of the numeric and categorical variables, but the user will also be able to select which variables they want to get summaries for.

summary.census <- function(object, numeric_vars = NULL, 
                           cat_vars = NULL, ...){
  
  #Setting the weight vector to the vector of PWGTP 
  weight_vector <- object[["PWGTP"]]
  
  if (is.null(numeric_vars)){
    #Saving all of the numeric variables in the tibble
    all_numeric <- names(object)[sapply(object, is.numeric)]
    
    #Removing PWGTP and any time-based variables. Also removing year
    #so it can be treated as categorical
    numeric_vars <- setdiff(all_numeric, c("PWGTP", "JWAP", "JWDP",
                                           "year"))
  }
  
  if (is.null(cat_vars)){
    #Saving all of the columns in the tibble as we can't check if
    #a variable is a factor or character in the same line
    all_cols <- names(object)
    
    #Now checking to see if each column pulled through is either a 
    #character or factor
    cat_vars <- all_cols[sapply(object, function(col) 
      is.factor(col) || is.character(col))]
    
    #Makes sure year is treated as categorical
    if ("year" %in% all_cols && !"year" %in% cat_vars){
      cat_vars <- c(cat_vars, "year")
    }
  }
  
  #Initializing list to save summaries in
  summary_list <- list()
  
  #Calculating weighted means and standard deviations
  if (length(numeric_vars) > 0){
    #Initializing list to save numeric summaries in
    num_list <- list()
    
    #Looping through each numeric variable and calculating the mean
    #and standard deviation
    for (var in numeric_vars){
      numeric_vector <- object[[var]]
      
      #Calculating weighted mean using sum(x*w) / sum(w)
      weighted_mean <- sum(numeric_vector * weight_vector, na.rm = T) / sum(weight_vector, na.rm = T)
      
      #Calculating weighted standard deviation using 
      #sqrt(sum(x^2*w)/sum(w)-weighted_mean^2)
      weighted_sd <- sqrt((sum((numeric_vector^2) * weight_vector, 
                               na.rm = TRUE) / 
                             sum(weight_vector, na.rm = TRUE)) - 
                            (weighted_mean^2))
      
      #Saving weighted mean and standard deviation calculation
      num_list[[var]] <- c(mean = weighted_mean, sd = weighted_sd)
    }
    
    #Combining into data frame
    summary_list[["numeric_summaries"]] <- do.call(rbind, num_list)
  }
  
  #Calculating counts for categorical variables
  if (length(cat_vars) > 0){
    #Initializing list to save counts in
    cat_list <- list()
    
    #Looping through each categorical variable
    for (var in cat_vars){
      #Converting to factor for proper counting
      cat_vector <- as.factor(object[[var]])
      cat_list[[var]] <- table(cat_vector)
    }
    
    summary_list[["categorical_summaries"]] <- cat_list
  }
  
  return(summary_list)
}

Now I’m gonna make a generic plot() function for a census class tibble. The user is required to specify one categorical and one numerical variable. The function will create a boxplot of the numerical variable at the different levels of the categorical variable.

plot.census <- function(object, numeric_var, cat_var){
  #Checking to make sure one numeric variable was specified
  if (missing(numeric_var) || length(numeric_var) != 1 || 
      !is.character(numeric_var)){
    stop("Error: You must specify one numeric variable as a string.")
  }
  
  #Checking to make sure one categorical variable was specified
  if (missing(cat_var) || length(cat_var) != 1 || 
      !is.character(cat_var)){
    stop("Error: You must specify one categorical variable as a 
         string")
  }
  
  #Creating boxplot with aes(weight = PWGTP)
  p <- ggplot(object, aes(x = as.factor(get(cat_var)), 
                          y = get(numeric_var),
                          weight = PWGTP)) +
    geom_boxplot(fill = "navyblue", alpha = 0.7, 
                 color = "darkgreen") +
    labs(x = cat_var, y = numeric_var, 
         title = paste("Weighted Boxplot of", numeric_var, "by", 
                       cat_var)) +
    theme_minimal()
  
  return(p)
}
